# v5 组装审计（2026-09-30）：被删序列里还有独有内容

**背景**：2026-09-23 按用户决定从递交序列里删掉三条「内部重复副本」

## 逐条复核结果

`diamond blastp`，统计「在 v5 里找不到 ≥99 % 全长对应」的蛋白数；DNA 层面另做
`minimap2 -x asm5` 的 ≥99 % 分段。

| `wCchiA_contig_04` | 13,032 | 12 | 9 | **3**（其「唯一段」2,439 bp 的 3 个蛋白**全部**有 ≥99 % 对应） | ✅ 纯副本，可删 |

### contig_08 的构成（DNA ≥99 % 分段）

```
    1-  2640 ( 2640 bp)  副本（contig_06）      2,641-  3071 (  431 bp) ★唯一
 3072-  3129 (   58 bp)  副本                     3130 (     1 bp) ★唯一
 3131- 24634 (21504 bp)  副本（contig_06/07）   24635- 27740 ( 3106 bp) ★唯一
27741- 28705 (  965 bp)  副本
```
→ 25,167 bp 是副本，**3,538 bp（2 段）在 v5 里没有任何对应**。

### 那 3,538 bp 上是什么

meta 模式下 6 个蛋白，**全部**在 v5 里没有 ≥99 % 对应。其中 4 个就是 v4 主 scaffold 的
`strainA_01356`–`01359`（152 / 137 / 127 / 303 aa）—— **连续 4 个核心直系同源基因**：

| v4 蛋白 | 长度 | 对 wMel | 对 wRi | 对 wPip |
|---|---|---|---|---|
| strainA_01356 | 152 aa | 93.4 % | 95.4 % | 82.2 % |
| strainA_01357 | 137 aa | 95.6 % | 97.1 % | 81.8 % |
| strainA_01358 | 127 aa | **100 %** | **100 %** | 95.3 % |
| strainA_01359 | 303 aa | 96.7 % | 97.0 % | 90.8 % |

在**全部 10 个基因组**里都存在且编号连续（wMel_00859–00862、wPip_01295–01298、
wRi_00894–00897…），即一个保守的共线基因块。**v5 里完全没有它们**
（6 帧翻译、放宽到 E<10 的 `--sensitive` 搜索也找不到）。

### ptg000003l 的两面性

- 43 个蛋白里 32 个在 v5 里没有 ≥99 % 对应（24 个连 ≥90 % 都没有）→ 有大量独有内容；
- 但它本身是**嵌合/发散**的：8,763 bp 与 **B 箱 ≥99 % 相同**，其余与 wMel 仅 ~90 %、
  与主 scaffold 只有 36 % 长度 93 % 同一（`docs/design/PAPER_I_DESIGN.md` §unplaced 剔除）。
  → 收它进 wCchiA 记录会把「嵌合/可能的异株序列」写成 wCchiA 的一部分，需谨慎。
